# FirstPlace.games

Este repositorio es **el sitio entero** de https://firstplace.games: la portada, los juegos, el globo, los calendarios y el blog.

Cloudflare Pages (proyecto `firstplace`) publica automáticamente cada cambio que entra en la rama `main`. No hay paso de build: los archivos se sirven tal cual.

## Cómo publicar un cambio

1. Editar los archivos en `~/Desktop/FIRST PLACE-A-CLOUDFLARE/` (sigue siendo la copia de trabajo).
2. En GitHub, entrar a la carpeta que corresponde (la raíz, `juegos/`, `blog/`...).
3. **Add file → Upload files**, arrastrar los archivos modificados y apretar **Commit changes**.
4. En uno o dos minutos Cloudflare publica. Se puede seguir en Cloudflare → Workers & Pages → firstplace → Deployments.

Arrastrar **archivos**, no la carpeta del Escritorio entera, y hacerlo dentro de la carpeta correcta del repo, para que cada archivo quede en su lugar.

Todo lo que se sube acá queda público en internet. No subir respaldos ni notas.
